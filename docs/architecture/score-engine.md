# Score Engine

Score Engine은 기술적 분석, 재무, 뉴스, 공시, 수급, 시장 위험도의 6개 축 계약을 고정한다. 가중치는 `score_weights`에서 버전 관리한다.

현재 구현은 여섯 축을 다음 데이터에 연결한다.

- 기술적 분석: RSI, MACD, 이동평균, ADX, MFI, SuperTrend
- 재무: 영업이익률, 순이익률, 자기자본비율
- 뉴스: 규칙 기반 뉴스 감성 점수
- 공시: 최근 공시 수와 고위험 공시 플래그
- 수급: 외국인·기관 합산 순매수와 외국인 보유량 대비 비율
- 시장 위험도: 종목별 활성 투자유의 신호

개별 외부 Provider가 실패하면 전체 Score 요청을 실패시키지 않고 해당 축만 `unavailable`로 반환한다. 가용 축끼리 정규화한 `overall_score`와 전체 가중치 대비 `coverage_ratio`를 함께 제공하며, 커버리지가 100% 미만이면 `is_partial: true`다. 미국 종목처럼 DART 재무나 국내 수급 데이터가 없는 경우에도 이 규칙을 적용한다.

재무 축은 미래 데이터 사용을 막기 위해 평가 시점의 직전 회계연도 연간 보고서만 요청한다. 모든 축의 정규화 규칙은 설명 가능한 결정론적 계산이며 Score Engine 버전과 함께 변경 이력을 관리한다.

점수 및 참고 시그널은 백테스트 검증 전까지 `experimental`이다. `TechnicalScoreStrategy`는 각 시점까지 계산된 지표만 사용하고 Backtest Engine의 T+1 체결 규칙을 그대로 적용한다.
