## 이번에 보류한 모델

- FinBERT: 현재 보관된 신규 제목 250건은 아직 3거래일 뒤 결과 라벨이 없다. 지금 미세
  조정하면 표본 누출과 과적합 가능성이 커서 라벨 누적 후 적용한다.
- OHLC-Vol: 현재 장기 백필 파일에는 조정 종가만 있고 과거 고가·저가·시가가 없다. OHLC를
  다시 수집하기 전에는 해당 변동성 추정량을 정확하게 복원할 수 없어 임의 생성하지 않았다.
