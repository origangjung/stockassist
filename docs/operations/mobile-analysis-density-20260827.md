# 모바일 분석 결과 밀도 개선: 2026-08-27

## 발견한 문제

`390x844` 화면에서 최종 분석이 완료된 페이지의 CSS 높이가 10,075px였다. 중복 렌더링은 아니었지만
최종 판정 안의 회의록·모델 표와 아래 전문 AI 근거가 모두 기본으로 펼쳐져 핵심 결과를 훑기 어려웠다.

## 수정

- 최종 판단, 신뢰도, 핵심 근거, 참고 레벨은 처음부터 표시한다.
- 회의록과 모델 상태는 `회의록과 모델 상태 보기`로 묶었다.
- AI 사무실과 실시간 분석 피드는 처음부터 표시한다.
- 전문 AI별 상세 근거와 반대 의견은 `전문 AI 근거와 반대 의견 보기`로 묶었다.
- 두 영역은 키보드와 스크린 리더가 상태를 인식할 수 있는 네이티브 `details`/`summary`를 사용한다.

## 결과

- 모바일 기본 페이지 높이: 10,075px에서 7,343px로 약 27% 감소
- 두 상세 영역을 펼치면 기존 회의록, 모델 상태, 전문 AI 근거와 반대 의견이 모두 복원됨
- 닫힌 상태와 열린 상태 모두 가로 넘침 0px
- TypeScript 검사 및 프론트 단위 테스트 19개 통과
- Playwright 전체 실행: 17개 통과, 화면별 조건 테스트 19개 제외, 실패 0개
- Next.js 운영 빌드와 Docker 웹 컨테이너 반영 성공
