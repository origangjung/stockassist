# 차트 패턴 성공률 검증 (2026-08-22)

## 검증 설계

- 대상: 미국 주식 54종목, 종목당 최대 1,800거래일
- 패턴 엔진: `patterns-2026.2`
- 패턴은 해당 거래일 종가까지의 캔들로만 감지
- 신호 확인 다음 거래일 시가에 진입 가능한 것으로 간주
- 1·5·10거래일 뒤 종가 방향 평가
- 같은 패턴이 연속 표시되면 첫날만 하나의 사건으로 계산
- 절대수익 방향과 SPY 초과수익 방향을 별도 평가
- 결과 보고서: `artifacts/pattern-evaluation/patterns-20260822.json`

## 판정

- 패턴 분석은 현재처럼 **설명 가능한 차트 상태 정보**로만 제공한다.
- UI의 백분율은 과거 성공 확률이 아니라 규칙 일치 강도라는 표현을 유지한다.
- 패턴만으로 상승·하락 확률이나 거래 행동을 만들지 않는다.
- 하락 삼각수렴 규칙은 향후 국면·거래량 확인 조건을 추가한 후보와 비교한다.
- 매수·매도 압력은 과거 호가·체결 원장이 없어 이번 일봉 백테스트 대상이 아니다.
  이는 실시간 상태값으로만 표시한다.

## 선택형 정책 후속 검증

과거 구간에서만 패턴·거래량·추세 필터를 선택하고 다음 구간에서 검증하는 5개
확장형 워크포워드를 추가했다. 전체 방향을 예측하지 않고 이중 천장과
헤드앤숄더가 감지된 경우의 10거래일 SPY 상대 약세만 참고 신호로 제한했다.

|---|---:|

절대 주가 하락 적중률은 49.25%이므로 `하락 예측`으로 표시하지 않는다. 화면과
리포트에는 `10일 SPY 상대 약세 참고`로만 표시하고, 나머지 패턴은 형태 설명으로
유지한다. 선택형 정책 원본 결과는
`artifacts/pattern-evaluation/selective-policy-20260822.json`에 있다.
