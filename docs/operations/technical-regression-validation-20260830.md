# 기술 AI 초과수익 회귀 검증 기록: 2026-08-30

## 목적

기존의 단순 상승·하락 이진 분류가 아주 작은 가격 변화까지 억지로 맞히는 문제를
줄이기 위해, 10거래일 뒤 SPY 대비 초과수익을 직접 예측하고 절댓값 1% 이내는
중립으로 처리하는 후보를 검증했다.

## 검증 설계

- 데이터: `datasets/local-ai-incremental/market/technical.csv`
- 전체 데이터: 215,557행
- 외부 검증 데이터: 143,973행, 시간순 5개 구간
- 모델: 표준화한 기술 피처와 Ridge 회귀
- 내부 선택: 각 외부 학습 기간 안에서만 `alpha=0.1, 1, 10, 100` 비교
- 누수 방지: 학습·검증 사이 10개 타임스탬프 제거
- 자원 제한: Docker와 GPU를 사용하지 않고 BLAS 1스레드로 실행
- 안전장치: 보고서만 생성하며 운영 모델은 자동 교체하지 않음

## 결과

모든 외부 구간에서 가장 강한 규제값인 `alpha=100`이 선택됐다. 현재 기술 피처의
신호가 약해 모델이 예측값을 0 근처로 수축한 결과다. MAE가 단순 기준보다 나쁘고,
실제 매매에 해당하는 비중과 방향 적중률도 부족하므로 후보는 승격하지 않는다.
