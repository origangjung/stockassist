## 실패 진단 개선

기존 PowerShell 실행기는 Python 작업 실패를 예외로 다시 던져 작업 스케줄러가 `FFFD0000`처럼 원인을
구분하기 어려운 값을 기록할 수 있었다. 실행기를 다음과 같이 변경했다.

- 정상 수신은 종료 코드 `0`을 반환한다.
- 연결됐지만 검증 시간 중 시세가 없으면 기존 진단 보고서를 보존하고 종료 코드 `2`를 반환한다.
- 실행기 자체 문제는 민감정보 없는 실패 보고서를 만들고 종료 코드 `3`을 반환한다.
- 보고서에는 상태, 시장, 종료 시각, 종료 코드와 `contains_credentials=false`만 기록한다.

실제 검증에서 미국 장중 정상 경로는 시세 269건과 코드 `0`, 국내 장 마감 무수신 경로는 코드 `2`와
`connected_without_quotes` 보고서를 남겼다.
