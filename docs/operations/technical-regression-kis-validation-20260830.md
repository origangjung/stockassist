# 기술 AI KIS 투자자 수급 회귀 검증 기록: 2026-08-30

## 목적

국내 종목의 10거래일 뒤 KODEX 200 대비 초과수익을 예측할 때 외국인·기관·개인
순매수 흐름이 가격·시장 문맥에 추가적인 정보를 제공하는지 검증했다.

## 데이터와 안전성

- 데이터: `datasets/local-ai-incremental/kis-flow/investor_flow.csv`
- 기간: 2024-09-30~2026-08-13
- 규모: 12,611행, 30종목, 고유 시점 455개
- 원천: KIS 종목별 투자자매매동향 조회 API
- 기본 피처: 가격 5개, 시장·상대수익 문맥 4개
- KIS 후보: 외국인·기관·개인 순매수 비율과 5일·20일 평균, z-score,
  외국인·기관 방향 일치도 등 10개
- 주문 API는 호출하지 않으며 API 키와 원본 응답은 결과물에 저장하지 않음
- 초과수익 절댓값 0.5% 미만 행은 원본 생성 단계에서 제외됨

외부 5개 시간 구간마다 과거 내부 데이터에서만 Ridge 규제값과 피처 묶음을
선택했다. 학습·검증 경계의 10개 시점을 제거했고 Docker·GPU 없이 BLAS
1스레드로 실행했다.

## 결과

|---|---:|---:|

| 0 예측 기준 MAE | 0.086655 | 0.086655 |

| 상승·하락 신호 발생률 | 33.11% | 44.37% |

| 최악 구간 MAE 개선폭 | -0.000827 | -0.000721 |

KIS 수급 묶음은 앞 3개 구간에서 내부 선택됐지만, 첫 구간에서는 0 예측 기준보다
나빴고 뒤 2개 구간에서는 기본 피처만 선택됐다. 동일 표본의 기본 모델보다 MAE,
균형 정확도, 방향 적중률이 모두 낮아 KIS 수급의 순수 추가 효과는 확인되지 않았다.

국내 종목군의 가격·시장 문맥 자체는 전체 기준보다 개선됐지만 고유 시점이 최소
승격 조건 500개보다 45개 부족하고 최악 구간 개선폭도 음수다. 따라서 기본 모델과
KIS 혼합 모델 모두 운영에 승격하지 않는다. 500시점 이상 누적된 뒤 고정된 같은
검증 방식으로 다시 판단한다.
