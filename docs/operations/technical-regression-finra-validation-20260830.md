# 기술 AI FINRA 수급 회귀 검증 기록: 2026-08-30

## 목적

10거래일 뒤 SPY 대비 초과수익을 예측할 때 가격 문맥에 FINRA 일별 공매도 거래
피처를 추가하면 안정적인 개선이 생기는지 확인했다.

## 데이터와 피처

- 데이터: `datasets/local-ai-incremental/investor_flow.csv`
- 기간: 2025-09-25~2026-08-14
- 규모: 17,540행, 85종목, 고유 시점 223개
- 기본 피처: 1일·5일 수익률, 20일 이평 괴리, 20일 변동성, 거래량 비율
- FINRA 후보: 당일 공매도 비율, exempt 비율, 5일·20일 공매도 비율,
  5일 변화량, 20일 대비 보고 거래량
- 주의: 원본 생성 단계에서 초과수익 절댓값 0.5% 미만 행은 제외됨

각 외부 학습 기간의 내부 시간 검증에서 `가격 문맥만`과 `가격 문맥+FINRA`를
비교했다. 외부 검증 결과를 보고 피처를 선택하지 않았고, 학습·검증 경계에서는
10개 시점을 제거했다. Docker와 GPU 없이 BLAS 1스레드로 실행했다.
