# 고급 OHLCV 및 횡단면 후보 피처 검증 기록

## 목적

공개 주식 분석 프로젝트의 학습 파이프라인을 조사했지만 재사용 가능한 CSV, Parquet,
JSONL 학습 데이터는 없었다. 대신 과거 가격에서 유동성·변동성·시장 국면 피처를 만드는
설계 아이디어를 참고해 StockPilot이 이미 보유한 시점 정합 데이터에 독립 구현한 후보
피처를 추가했다. 외부 저장소의 코드는 복사하지 않았고 새 API나 유료 데이터도 사용하지
않았다.

## 후보 피처

- 20·60거래일 수익률과 60거래일 변동성
- 252거래일 변동성 백분위
- 최근 수익률 왜도·초과첨도·1시차 자기상관
- 상승일 비율, 추세 효율, 60거래일 고점 대비 현재 낙폭
- 하락 변동성 대비 상승 변동성 비율
- 같은 시점 종목군 내 5·20거래일 수익률과 변동성 순위
- 같은 시점 종목군의 수익률 분산과 상승 종목 비율

모든 시계열 값은 해당 행까지의 값만 사용한다. 횡단면 값도 동일한 타임스탬프에 존재하는
종목만 사용한다. 첫 253거래일은 충분한 과거 창이 없으므로 후보 데이터에서 제외했다.

## 1차 walk-forward 비교

모든 비교는 같은 194,532행, 5개 시간 구간, 5타임스탬프 purge, 동일한 로지스틱 회귀
규제 후보를 사용했다.

| 피처 묶음 | 정확도 | 균형정확도 | 최악 구간 균형정확도 | Brier | ROC AUC |
|---|---:|---:|---:|---:|---:|
| 기존 7개 | 50.69% | 50.62% | 49.70% | 0.2500 | 0.5068 |
| 기존 + 고급 16개 | 50.36% | 50.37% | 49.71% | 0.2503 | 0.5062 |
| 기존 + 추세 그룹 | 50.63% | 50.59% | 49.98% | 0.2501 | 0.5056 |
| 기존 + 분포위험 그룹 | 50.12% | 50.06% | 48.85% | 0.2501 | 0.5025 |
| 기존 + 횡단면 그룹 | 51.03% | 50.90% | 49.85% | 0.2499 | 0.5122 |
| 모든 안전 피처 | 50.43% | 50.38% | 49.96% | 0.2508 | 0.5067 |

횡단면 그룹은 평균 지표가 소폭 좋아졌지만 최악 구간이 무작위 기준 아래였다. 사후에 가장
좋은 묶음을 고른 편향을 제거하기 위해 기존 피처와 횡단면 피처를 내부 구간에서만 선택하는
5x3 중첩 시간 검증을 추가로 실행했다.

## 중첩 시간 검증과 판정

중첩 검증은 횡단면 피처를 5개 외부 구간 중 2개에서만 선택했다. 전체 결과는 정확도
50.83%, 균형정확도 50.82%, ROC AUC 0.5104였지만 다수 클래스 기준선 50.95%보다
0.12%p 낮았다. 최악 구간의 기준선 개선폭은 -2.14%p였다.

따라서 `promotion_ready=false`이며 운영 모델과 운영 피처 계약은 변경하지 않았다. 중첩
검증 원본 보고서는
`artifacts/local-ai-candidates/advanced-ohlcv-20260815/technical-nested-report.json`에
저장했다. 횡단면 피처는 향후 종목군 확대나 섹터 중립 라벨 실험에서 다시 평가할 후보로만
보존한다.
