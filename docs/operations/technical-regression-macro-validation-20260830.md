# 기술 AI 거시 국면 회귀 검증 기록: 2026-08-30

## 목적

기술 AI의 10거래일 SPY 대비 초과수익 회귀 후보에 당시 알 수 있었던 FRED 시장
국면을 추가하면 기본 가격 피처보다 안정적으로 개선되는지 확인했다.

## 검증 설계

- 데이터: `datasets/local-ai-incremental/forward-risk-enriched/technical.csv`
- 후보 피처: VIX, 미국 10년물 금리, 10년-2년 금리차, 연방기금금리,
  달러 지수 20일 변화율
- 비교 방식: 각 외부 학습 구간 내부에서만 `기본`과 `기본+거시` 피처를 선택
- 외부 검증: 143,973행, 시간순 5개 구간, 경계 10개 타임스탬프 제거
- 실행 자원: Docker·GPU 미사용, BLAS 1스레드

## 결과

| 지표 | 기본 회귀 | 거시 피처 내부 선택 |
|---|---:|---:|
| MAE | 0.040826 | 0.040850 |
| 0 예측 기준 MAE | 0.040739 | 0.040739 |
| 초과수익 상관계수 | 0.0482 | 0.0460 |
| 3상태 균형 정확도 | 33.87% | 33.96% |
| 상승·하락 신호 발생률 | 3.32% | 4.06% |
| 신호 방향 적중률 | 50.80% | 50.53% |

거시 피처는 5개 외부 구간 중 3개에서 내부 검증으로 선택됐지만 전체 MAE와 상관,
방향 적중률이 모두 기본 회귀보다 나빠졌다. 시장 국면은 일부 시기에 관계가 있어도
현재 선형 구조에서는 기간 전체에 안정적인 종목별 초과수익 신호가 아니므로 승격하지
않는다.

수급 후보는 17,540행이지만 고유 시점이 223개(2025-09-25~2026-08-14)에 불과하다.
별도 실험은 하되 최소 500개 시점 전에는 운영 승격을 막는다. 실적 예상 이벤트는
Alpha Vantage 키가 설정된 뒤 PIT 데이터가 실제 누적되어야 결합할 수 있다.
