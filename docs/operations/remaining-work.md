## 배포와 무관하지만 계속 필요한 작업

### 1. 학습 데이터 누적

- 뉴스 AI는 시간 구간이 16개뿐이라 최소 수백 개 시점, 가능하면 수천 건까지 정기적으로 누적해야 한다.
- 재무 AI는 종목·연도·섹터 범위를 더 넓히고 공시 수정 이력을 시점 기준으로 보존해야 한다.
- 재무 AI는 PIT 기준 PER·PBR·PSR·ROE, 실적 예상치 대비 서프라이즈, 가이던스 변화와 섹터 내 순위를 누적한 뒤 섹터 중립 라벨로 다시 검증해야 한다.
- PIT PER·PBR·PSR·ROE 검증은 마쳤지만 평균 개선폭이 작고 최저 구간이 악화됐다. 새로운 공시 시점을 누적하고, 피처 그룹 선택을 안쪽 시간 구간에 한정한 뒤 손대지 않은 미래 구간에서 다시 평가한다.
- 수급 AI는 FINRA short volume 외에 합법적으로 사용할 수 있는 short interest와 기관 수급 시계열을 더 오래 누적해야 한다.
- 데이터 누적 후 동일 타깃과 동일 검증 기준으로만 재학습한다.

현재 walk-forward 결과는 위험 AI만 모든 구간에서 의미 있는 신호를 유지했다. 기술·재무·뉴스·수급 AI는 품질 게이트를 통과하기 전까지 참고 정보 또는 unavailable 상태를 유지한다.

### 2. 외부 자격 증명이 필요한 검증

- KIS 키가 설정되지 않아 국내·미국 WebSocket 구독, 해제, 재연결과 REST fallback 실검증은 아직 할 수 없다.
- Toss 장시간 soak test는 실제 장 운영 시간에 별도로 실행해야 한다.
- 429를 고의로 만들기 위한 실서비스 과다 호출은 무료 한도와 제공자 정책 보호를 위해 수행하지 않는다. 재시도 동작은 자동 테스트로 검증한다.

### 3. 모델 승격

- 기술 AI walk-forward 균형정확도: 50.82%, 최저 구간 49.49%
- 재무 AI walk-forward 균형정확도: 51.27%, 최저 구간 49.47%
- 뉴스 AI walk-forward 균형정확도: 41.80%, 최저 구간 27.78%
- 수급 AI walk-forward 균형정확도: 47.05%, 최저 구간 45.49%
- 위험 AI walk-forward 균형정확도: 56.71%, 최저 구간 53.73%, AUC 0.6013

운영 모델 교체는 평균 성능뿐 아니라 최저 구간, 기준선 대비 개선폭, AUC, Brier score와 calibration 조건을 모두 통과할 때만 진행한다. 전문 AI의 타깃과 데이터 가용성이 충분히 정렬되기 전에는 학습형 종합 AI를 승격하지 않는다.

## 안전 원칙

1. `.env`, API key, client secret, 계좌 식별자는 Git·로그·문서·fixture에 넣지 않는다.
2. 모델 결과는 참고 신호이며 `is_investment_advice=false` 원칙을 유지한다.
3. 데이터의 당시 공개 시점 이후 값만 학습 피처로 사용한다.
4. 품질 게이트를 통과하지 못한 모델은 정확도 숫자를 높이기 위해 임의로 승격하지 않는다.
