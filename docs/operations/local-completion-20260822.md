# 배포 제외 최종 검증 기록: 2026-08-22

## 데이터와 모델

- KIS 수급 데이터는 30종목 12,746행, 19개 피처로 확장했다.
- KIS 후보는 정확도 58.37%, 균형 정확도 53.39%, AUC 0.5241을 기록했다.
- 위험 AI는 확률 보정 후 Brier 0.2239, 보정 오차 0.0491, AUC 0.6278을 기록했다.
- 두 후보 모두 시간 구간별 다수 클래스 개선폭이 안정적이지 않아 운영 모델로 승격하지 않았다.
- FINRA는 절대 초과수익 0.5% 미만 사례를 제외해 17,360행으로 재구성했지만 승격 기준은 넘지 못했다.
- 뉴스는 무료 한도 안에서 하루 22종목씩 최근 4주를 순환 수집하도록 변경했다.

## 실시간 검증

- 미국 KIS WebSocket을 AAPL과 MSFT로 600초 유지했다.
- AAPL 1,304건, MSFT 958건, 총 2,262건을 수신했다.
- 연결 시도 1회, 성공 1회, 재연결 0회, 마지막 오류 없음이었다.
- 보고서에는 자격증명 원문을 저장하지 않았다.

- 백엔드 테스트: 429개 통과
- 프론트 단위 테스트: 18개 통과

## 남은 제한

- 뉴스 AI는 검증 표본이 200행 미만이므로 자동 수집으로 계속 누적한다.
- KIS·위험 후보는 평균 지표가 개선됐지만 최악 시간 구간이 승격 기준을 넘지 못했다.
- 배포, 도메인, HTTPS, 외부 모니터링은 이번 범위에서 제외했다.
- 운영 모델 자동 교체는 비활성화 상태를 유지한다.
