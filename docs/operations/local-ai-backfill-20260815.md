# 로컬 AI 과거 데이터 백필 및 후보 검증 기록

## 목적

2026-08-15 기준으로 무료 공급자 범위에서 과거 데이터를 다시 수집하고, 모든 전문 AI의 정답을
`이후 5거래일 SPY 대비 초과수익이 양수인가`로 통일했다. 학습 후보는 운영 모델과 분리된
`datasets/local-ai-backfill-20260815/` 및
`artifacts/local-ai-candidates/backfill-20260815/`에만 저장했다.

제외했다. 기사 수나 정답을 임의로 만들지 않는다.

## 중첩 시간 검증

모든 후보는 5개 외부 구간, 3개 내부 구간, 5거래일 purge를 사용했다. 피처 묶음과 규제 강도는
각 외부 검증 구간을 보기 전에 내부 과거 구간에서만 선택했다.

| 후보 | 검증 행 | 정확도 | 균형정확도 | ROC AUC | 기준선 개선 | 판정 |
|---|---:|---:|---:|---:|---:|---|
| 기술 | 144,797 | 50.44% | 50.45% | 0.5061 | -0.51%p | 기각 |
| 재무 | 915 | 51.48% | 51.52% | 0.5006 | +1.20%p | 기각 |
| 수급 | 12,325 | 45.17% | 45.13% | 0.4454 | -6.02%p | 기각 |
| 위험 | 144,797 | 56.60% | 57.90% | 0.6185 | -6.76%p | 기각 |
| 종합 | 72,250 | 51.62% | 50.47% | 0.5125 | -0.32%p | 기각 |

위험 후보는 방향 구분 능력은 있었지만 클래스 불균형 때문에 단순 다수 클래스 기준선보다
정확도가 낮았고 확률 보정 오차도 15.10%였다. 재무 후보는 평균 개선폭이 양수였으나 ROC AUC가
무작위 수준이고 일부 시간 구간에서 기준선보다 낮았다. 따라서 어느 후보도 운영 artifact로
승격하지 않았다.

종합 후보는 뉴스 가용성 0을 명시하고 기술·재무·수급·위험의 과거 시점 예측만 사용했다.
전문 AI 자체의 신호가 약해 기준선을 이기지 못했으므로 기존 규칙 기반 종합 판단을 유지한다.

## 반복 실행

```powershell
docker compose --profile collection run --rm collector --mode all --market-limit 500
```

- 시장 데이터는 매일, 재무와 FINRA 수급은 7일 간격으로 증분 수집한다.
- 재무는 종목당 최대 40개 분기를 요청한다.
- 뉴스는 무료 일일 요청 한도를 넘지 않게 예약하며, 수집 후 최소 5거래일이 지난 행만 라벨링한다.
- 매월 `dataset-readiness.json`을 확인한 뒤 중첩 시간 검증을 다시 실행한다.
- 승격은 평균 수치뿐 아니라 모든 시간 구간의 기준선 개선, Brier score와 보정 오차를 통과할 때만 한다.

이번 작업은 무료 API와 로컬 CPU/GPU 자원만 사용했으며 유료 API 호출을 추가하지 않았다.
자격 증명은 `.env`와 컨테이너 환경 변수로만 전달했고 CSV, JSON, 로그에는 기록하지 않았다.
