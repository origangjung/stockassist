# 전체 AI 승격 작업 기록 (2026-08-22)

## 결론

승격 기준을 낮추거나 검증 구간을 보고 임의로 모델을 고르지 않았다. 현재 운영 가능한 모델은 수급 AI와 위험 AI이며, 나머지 모델은 아래 검증 결과에 따라 후보 상태로 유지한다.

| AI | 현재 상태 | 이번 작업 결과 |
|---|---|---|
| 기술 | 승격 보류 | 선택형 타깃과 추가 피처 모두 시기별 안정성 미달 |
| 재무 | 승격 보류 | 분류력은 개선됐으나 모든 구간의 다수 클래스 기준을 넘지 못함 |
| 뉴스·공시 | 승격 보류 | 기사 거래일 부족, SEC 공시 대체 후보는 방향 신호 없음 |
| 수급 | 운영 가능 | 기존 운영 모델 유지 |
| 위험 | 운영 가능 | `local-risk-1fb586e522e2` 유지 |
| 종합 | 승인 보류 | 현재 두 전문 AI 조합의 진단 정책이 검증 기준 미달 |

## 기술 AI

- 원본: 215,952건, 2,575개 거래 시점
- 최근 378거래일 롤링 학습과 임계값 0.5 적용
- 초과수익 절댓값 0.2% 필터: 표본 93.81% 유지, 최저 구간 기준 개선 -2.22%p
- 초과수익 절댓값 0.5% 필터: 표본 84.77% 유지, 최저 구간 기준 개선 -2.33%p
- 시장 상대 지표와 장기 추세 지표도 내부 검증에서 대부분 선택되지 않음

선택형 검증은 원본 표본의 50% 이상을 유지해야만 승격할 수 있도록 구현했다. 검증과 최종 후보 학습이 같은 결과 컬럼과 필터를 사용하도록 파이프라인도 연결했다.

## 재무 AI

83개 종목, 1,628건의 SEC 품질 데이터에서 기본 재무 피처가 가장 안정적이었다.

| 지표 | 결과 |
|---|---:|
| 정확도 | 59.73% |
| 기준 대비 개선 | +9.61%p |
| 균형 정확도 | 59.73% |
| ROC-AUC | 64.18% |
| 최저 구간 균형 정확도 | 54.56% |
| 최저 구간 기준 개선 | -5.12%p |

전체 분류력은 유효하지만 시기별 양성 비율 변화 때문에 엄격한 구간별 기준을 통과하지 못했다. 126·252 시점 롤링 창은 오히려 Brier score와 구간 정확도를 악화시켰다. PER·PBR·PSR·ROE, 성장 가속, 마진 변화, 거시 피처도 내부 검증에서 일관되게 선택되지 않았다.

## 뉴스·공시 AI

- 기존 기사 데이터: 232건이지만 고유 거래일은 18일뿐
- 정식 5x3 중첩 시계열 검증에는 최소 30개 이상의 서로 다른 거래일이 필요
- GDELT 백필은 네트워크 연결 후 HTTP 429가 반복되어 추가 호출을 중단
- GDELT 클라이언트에는 `Retry-After` 우선 지수 백오프를 적용
- SEC 8-K 이벤트 4,936건을 뉴스·공시 후보로 변환해 검증
- SEC 후보 결과: 정확도 54.02%, 기준 대비 -0.55%p, AUC 50.79%

SEC 이벤트 종류만으로 미래 초과수익 방향을 예측할 수 없었으므로 런타임 스키마를 교체하지 않았다. SEC 공시는 예측 모델보다 사실 근거로 계속 제공하는 것이 맞다.

## 종합 AI

현재 정책은 수급·위험 AI를 사용하지만 검증 정확도 51.94%, 기준 대비 -2.28%p이므로 승인되지 않았다. 전문 AI가 추가 승격되기 전까지 최종 확률을 강제로 만들지 않고 개별 근거를 표시한다.
