# 재무 AI PIT 밸류에이션 재검증: 2026-08-30

## 목적

현재 증분 재무 후보에 공시 당시 확인 가능했던 PER·PBR·PSR·ROE를 결합하고, 기본
6개 특성과 밸류에이션 포함 10개 특성을 시간순 중첩 검증으로 비교했다. 운영 모델은
자동 교체하지 않았다.

## 데이터 구성

- 입력 후보: `datasets/local-ai-incremental/labeled/financial.csv`
- 입력 행: 1,265행, 66종목
- 가격: 기존 기술 AI의 Toss 조정종가 `close_price` 재사용
- 가격 사용 시점: 공시일과 같은 날을 제외한 직전 거래일
- PIT 결합 결과: 1,187행, 62종목, 커버리지 93.83%
- 제외: 당시 공개 연간 공시 없음 38행, 발행주식수 없음 40행
- 가격 결측, 중복, 비유한 값, 미래 시점: 모두 0건
- 검증 표본: 238행, 119개 시점

## 검증 방식

- 바깥쪽 시간 구간 5개, 안쪽 시간 구간 3개
- 예측 기간과 같은 20시점 purge
- 내부 구간에서만 규제 강도, 클래스 가중치, 판정 임계값을 선택
- 내부 구간에서 기본 6개와 기본+PIT 밸류에이션 4개 중 하나를 선택
- 바깥쪽 평가 구간은 선택에 사용하지 않음
