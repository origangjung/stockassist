# 재무 AI PIT ROE 후보 검증 기록: 2026-08-14

## 목적

섹터·시장 중립 재무 후보에 당시 공개된 연간 10-K 기준 ROE를 추가해, 기존 성장성·수익성·안정성
6개 피처보다 미래 상대 성과를 더 안정적으로 구분하는지 검증했다. 운영 모델과 기존 데이터는
덮어쓰지 않았다.

## 시점 기준 구성

- SEC Company Facts에서 각 10-K의 최초 공개일, 순이익, 자본과 당시까지 공개된 발행주식수를 복원했다.
- 각 학습 행에는 그 행의 공시일 이하에서 가장 최근에 공개된 연간 스냅샷만 결합했다.
- ROE는 `순이익 / 자본`으로 계산하고 적자 기업을 제거하지 않도록 signed-log 변환값을 모델 피처로 사용했다.
- 원시 `pit_roe`는 감사 메타데이터이며 모델 입력에서 제외했다.
- 54종목 조회가 모두 성공했고 1,021행 중 997행(97.65%), 53종목에 PIT ROE가 결합됐다.
- 중복, 결측, 비유한 숫자, 미래 시각 오류는 모두 0건이며 후보 학습 준비 상태를 통과했다.
